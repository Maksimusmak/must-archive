# Media auto-population

## Included sources

No API key required:
- Jikan — anime and manga
- TVmaze — TV shows
- Open Library — books
- Wikipedia — broad fallback for movies, games and misc

Optional free API keys:
- TMDb — stronger movie and TV results
- RAWG — stronger game results

## Using it

1. Open **Add title**.
2. Search in **Ask Archiva**.
3. Choose a result and press **Populate fields**.
4. Review or edit the form.
5. Press **Save to cloud**.

Manual entry remains available. API keys are saved only in local browser storage on that device.

For trailers, the site uses a direct trailer URL when supplied by the source; otherwise it creates a YouTube search link for the title.
